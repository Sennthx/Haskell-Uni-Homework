# 11. Házifeladat

## 0. Modul név, típus szinonímák és előfeltételek

Hozzunk létre egy modult `Delivery` néven!

A feladat során neked kell eldönteni, hogyan hozod létre a konstrukciókat!

## 1. Minden egy jó tervvel kezdődik

### a) Mi is volt a pontos cím?

Hozzuk létre a `Node` algebrai adatszerkezetet a következő konstruktorral:`Node :: Char -> Node`!

### b) A következő saroknál pördüljön meg a tengelye körül, majd forduljon jobbra

Hozzuk létre az `Edge` algebrai adatszerkezetet a következő konstruktorral:`Edge :: Node -> Int -> Node -> Edge`!

### c) Úttalan utakon

Hozzuk létre a `Path` algebrai adatszerkezetet a következő konstruktorral:`Path :: [Edge] -> Path`!

### d) Akkor most rajzoljuk is fel

Példányosítsuk a `Show` típusosztályt az előbb definiált típusokra!

Az `Edge` esetén az alábbi módon nézzen ki: `<node1>--- <number> ---><node2>`

A többi típus esetében csak az eltárolt érték jelenjen meg!

### f) Várjunk, én itt már jártam...

Példányosítsuk az `Eq` típusosztályt a `Node` típusra!

## 2. Nem tudom kiszűrni az utca zajától

### a) Pontból pontba

Készítsük el a `fromNode, weight, toNode` függvényeket! Ezek a függvények csak egy `Node` típusú paramétert várnak, és visszaadják a megfelelő eltárolt értékeket!

A `fromNode` az első `Node` paramétert, a `weight` az `Int` paramétert, míg a `toNode` a második `Node` paraméter adja vissza az `Edge`-el konstruktárt objektumból.

### c) Várj, itt le kellett volna kanyarodnom. Újratervezés...

Készítsük el a `edges` függvényt, ami egy `Path` típusú objektumból képez a benne eltárolt `[Edge]` típusú értékbe!

## 3. Ismerem ezt a várost, mint a tenyeremet!

Valósítsuk meg a `allPathsFrom :: [Edge] -> Node -> [Path]` függvényt, ami visszaadja az összes lehetséges utat egy adott pontból! Ügyeljünk arra, hogy minden út szakaszt csak egyszer használhatunk fel!

## 4. Köszönjük, hogy a KisBoszi csomagküldő szolgáltatást választotta!

Valósítsuk meg a `shortestPath :: [Edge] -> Node -> Node -> Path` függvényt, ami megadja két pont között a legrövidebb utat! Továbbra is, minden út szakaszt csak egyszer használhatunk fel!

## Tesztek

A tesztekhez a következő kódra lesz szükség:

```haskell

t1,t2,t3,t4,t5,t6,t7 :: Node
t1 = Node 'A'
t2 = Node 'B'
t3 = Node 'C'
t4 = Node 'D'
t5 = Node 'E'
t6 = Node 'F'
t7 = Node 'G'

p1 = Path [Edge t1 0 t1]

p = Path [Edge t1 (-5) t1, Edge t1 1 t2, Edge t2 3 t3, Edge t2 5 t5, Edge t3 1 t4, Edge t4 1 t5, Edge t7 3 t6, Edge t6 1 t7, Edge t6 2 t5]

```

Ezt másoljátok be a megoldásotokba!
