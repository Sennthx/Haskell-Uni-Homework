# 11. Házifeladat

## 0. Modul név, típus szinonímák és előfeltételek

Hozzunk létre egy modult `Race` néven!

A feladat során neked kell eldönteni, hogyan hozod létre a konstrukciókat!

## 1. Nevezés

Hozd létre a `Mage` algebrai adatszerkezetet a következő konstruktorral: `Participant :: String -> Int -> String -> Double -> String -> Mage`!

Ez a típus tárolja el a versenyző nevét, rajtszámát, seprűjének a modeljét, a futamidejét, és a versenyző kedvenc színét!

### a) Bemutatkozás

Amenyiben szeretnénk megjeleníteni a versenyzőinket, az alábbi szöveggel muatkozzanak be: `My name is: <név>. I had the start number of <rajtszám> and I had <idő>s as finsih time. My broom is a <seprű-model>.`

## 2. Versenyre fel!

Adott egy versenyen résztvevők listája. Keressünk meg azt a versenyzőt, aki kevesebb, mint 97.0 másodperc alatt ért a célba, és közülük a legnagyobb rajtszámmal rendelkezik! Amennyiben nincs ilyen versenyző, adjunk vissza `Nothing`-ot!

Ezt a feladatot a `largestAndFastest :: [Mage] -> Maybe Mage` függvény segítségével írjuk meg!
